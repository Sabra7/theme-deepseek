# مشكاة — استوديو الثيم

ملف HTML واحد يعمل مباشرة بدون سيرفر أو تثبيت:
**`mishkat-theme-studio.html`**

## كيف تستخدمه

1. افتح الملف في المتصفح (Chrome أو Edge).
2. اختر الهدف من الأعلى:
   - **DSH** — ثيم لواجهة DeepSeek Harness.
   - **WEB** — توكنز تصميم لواجهة ويب.
   - **VENCORD** — ثيم ClearVision / Discord.
3. ابدأ من أحد الستايلات العشرة، ثم عدّل:
   - **اللوحة**: الخلفية، السطح، الحبر، التمييز، الألوان المشتقة، والتباين.
   - **الخطوط**: خط عربي + لاتيني + كود، الأحجام، وارتفاع السطر.
   - **الأيقونات**: Lucide / Tabler / Phosphor / Heroicons، الوزن، والحواف.
   - **الشكل**: الزجاج، نصف القطر، الظل، الكثافة، الحركة، والملمس.
4. اضغط **افتح الموجز**.
5. انسخ **الموجز** (أو نزّله) والصقه في المحادثة، وسأبني الثيم كما اخترته.

## ماذا يُخرج؟

- **الموجز**: كل اختياراتك بصيغة واضحة، مع تعليمات البناء.
- **CSS**: لـ DSH (جاهز للصق في CSS مخصص)، أو ويب، أو ملف `.theme.css` لـ Vencord.
- **JSON**: ثيم DSH (16 خانة)، أو توكنز ويب، أو متغيرات Vencord.
- **الأيقونات**: ٢٤ رمز DSH كامل مع `viewBox`، أو خريطة SVG للويب.

## ملاحظات

- الستايل الافتراضي **فيروز** مستوحى من ملف **ClearVision V7 Blur** الذي أرفقته: زجاج، حواف مضيئة، وظل عميق.
- الخطوط تُحمَّل من Google Fonts عند توفر الإنترنت، ومعها بدائل نظامية.
- يعمل النسخ على `file://`، ويحفظ اختياراتك محليًا في المتصفح.
- الملف محفوظ أيضًا كسكيل مثبّت باسم **`mishkat-theme-studio`** لاستخدامه في المرات القادمة.
- المصدر القابل للتعديل في `studio-src/`، وإعادة البناء: `node studio-src/build.mjs`.
