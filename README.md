# theme-deepseek

ثيمات وأدوات تخصيص **DeepSeek Harness** — بُنيت بواسطة استوديو **Mishkat**.

| المجلد | الوصف |
|---|---|
| [`theme/`](theme/) | ثيم **نيون** الكامل: CSS + بلجن الأيقونات + حلقات الاستخدام + المعاينات + أدوات البناء |
| [`studio/`](studio/) | **استوديو الثيم** (مولّد أحادي الملف بالعربية والإنجليزية) + نسخة السكيل + المصدر + اللقطات |

## الثيم (Neon)

- افتح [`theme/README.md`](theme/README.md) لطريقة التثبيت:
  - **CSS فقط**: الصق `theme/neon-dsh.css` في الإعدادات → عام → CSS مخصص.
  - **البلجن الكامل**: `theme/dsh-theme-neon` (CSS + أيقونات Lucide + حلقة السياق المتبقي وحصص 5h/الأسبوع).

## الاستوديو (Mishkat)

- افتح [`studio/index.html`](studio/index.html) في المتصفح لتصميم الثيم مباشرة.
- المصدر في [`studio/studio-src/`](studio/studio-src/).
- نسخة السكيل في [`studio/skill/`](studio/skill/).
